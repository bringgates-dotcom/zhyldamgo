# zhyldamGO на Netlify — чат клиент ⇄ Telegram

Структура:
```
public/index.html              приложение (фронтенд)
netlify/functions/api.mjs      бэкенд (одна функция, маршруты /api/*)
netlify.toml                   настройки Netlify
package.json                   зависимость @netlify/blobs (хранилище)
```

## Деплой (через GitHub)
Перетаскивание папки в Netlify Drop **не подходит**: функции с зависимостями так не собираются.

1. Загрузите папку `zhyldamgo-netlify` в новый репозиторий на GitHub.
2. Netlify → Add new project → Import an existing project → выберите репозиторий.
   Настройки сборки подхватятся из `netlify.toml`, build command не нужен.
3. До первого деплоя: Site configuration → Environment variables → Add a variable:
   - `BOT_TOKEN` — токен от @BotFather
   - `WEBHOOK_SECRET` — придумайте длинную случайную строку из букв, цифр, `_` и `-` (например `zgo_Kd83hF92jsLq0xPz`)
4. Нажмите Deploy. Вы получите адрес `https://что-то.netlify.app`.

## Подключение бота
1. Откройте в браузере (один раз):
   `https://ВАШ-САЙТ.netlify.app/api/setup?key=ВАШ_WEBHOOK_SECRET`
   Должно вернуться `"ok":true`. Так Telegram узнаёт, куда присылать ответы.
2. Добавьте бота в группу(ы) поддержки и курьеров (лучше сделать администратором).
3. Напишите в группе `/id`. Бот ответит chat id (например `-1001234567890`, минус тоже копируйте).
4. Добавьте переменные `SUPPORT_CHAT_ID` и `COURIER_CHAT_ID` (если группа одна, достаточно `SUPPORT_CHAT_ID`).
   Необязательно: `STAFF_USER_IDS` — Telegram ID сотрудников через запятую (каждый узнаёт свой, написав `/id` боту в личке).
5. Deploys → Trigger deploy → Deploy site. Новые переменные применяются только после нового деплоя.

## Проверка
Откройте сайт → «Поддержка» → «Написать в чат». Сообщение придёт в Telegram.
Нажмите на него → Reply → ответ появится в приложении от zhyldamGO (до ~4 секунд в открытом чате).
Диагностика: `https://ВАШ-САЙТ.netlify.app/api/health`.

## Как отвечать
- Reply на сообщение клиента, либо `/r КОД текст` (КОД из `#km65w` в заголовке).

## Ограничения
- Данные в Netlify Blobs: ответы хранятся 30 дней; служебные записи (коды обращений, защита от дублей) не чистятся, но занимают очень мало.
- Приложение опрашивает сервер раз в 4 секунды в чате и раз в 20 секунд вне чата. Нагрузка небольшая, но следите за лимитами вашего тарифа Netlify.
- Лимит запросов работает в пределах одного экземпляра функции. От серьёзного спама лучше добавить правила Rate limiting в панели Netlify.
- Номера заказов считает приложение, на разных телефонах они могут совпасть. Поэтому в Telegram есть уникальный `#код`.
